# Salesforce

> Salesforce is a cloud-based customer relationship management (CRM) platform providing a comprehensive suite of enterprise APIs across sales, service, marketing, commerce, analytics, and AI (Agentforce/Einstein). This file indexes the Salesforce API surface as cataloged by API Evangelist.

Generated by the API Evangelist enrichment pipeline (method: generated) from apis.yml and repo artifacts on 2026-06-20. Current platform API version: v67.0 (Summer '26). Base pattern: https://{instance}.salesforce.com/services/data/v{version}. Auth: OAuth 2.0 Bearer.

## Core Platform APIs
- [Salesforce REST API](https://developer.salesforce.com/docs/atlas.en-us.api_rest.meta/api_rest/): CRUD, SOQL/SOSL, composite over org data.
- [Salesforce SOAP API](https://developer.salesforce.com/docs/atlas.en-us.api.meta/api/): Enterprise/Partner SOAP interface.
- [Bulk API 2.0](https://developer.salesforce.com/docs/atlas.en-us.api_bulk_v2.meta/api_bulk_v2/): Asynchronous large-volume ingest/query.
- [Composite API](https://developer.salesforce.com/docs/atlas.en-us.api_rest.meta/api_rest/resources_composite.htm): Bundle dependent REST requests.
- [GraphQL API](https://developer.salesforce.com/docs/platform/graphql/guide/graphql-about.html): GraphQL over Salesforce data.
- [UI API](https://developer.salesforce.com/docs/atlas.en-us.uiapi.meta/uiapi/): Layout, picklist, record UI metadata.
- [Tooling API](https://developer.salesforce.com/docs/atlas.en-us.api_tooling.meta/api_tooling/): Developer tooling / Apex metadata.
- [Metadata API](https://developer.salesforce.com/docs/atlas.en-us.api_meta.meta/api_meta/): Retrieve/deploy customizations.
- [Actions API](https://developer.salesforce.com/docs/atlas.en-us.api_action.meta/api_action/actions_intro.htm): Invoke standard/custom actions.
- [Apex REST API](https://developer.salesforce.com/docs/atlas.en-us.apexcode.meta/apexcode/apex_rest.htm): Custom Apex web services.

## Events & Streaming
- [Pub/Sub API](https://developer.salesforce.com/docs/platform/pub-sub-api/guide/pub-sub-api-intro.html): gRPC event publish/subscribe (see grpc/salesforce-pubsub-api.proto).
- [Streaming API](https://developer.salesforce.com/docs/atlas.en-us.api_streaming.meta/api_streaming/): CometD/Bayeux push.
- [Platform Events](https://developer.salesforce.com/docs/atlas.en-us.platform_events.meta/platform_events/): Custom event-driven integration.
- [Change Data Capture](https://developer.salesforce.com/docs/atlas.en-us.change_data_capture.meta/change_data_capture/): Record change events.

## AI / Agentforce
- [Agentforce Agent API](https://developer.salesforce.com/docs/ai/agentforce/guide/agent-api.html): Converse with AI agents.
- [Models API](https://developer.salesforce.com/docs/ai/agentforce/guide/models-api.html): LLM access via the Einstein Trust Layer.
- [Einstein Platform Services](https://metamind.readme.io/): Vision and language models.
- MCP: official Salesforce DX MCP Server ([@salesforce/mcp](https://github.com/salesforcecli/mcp)).
