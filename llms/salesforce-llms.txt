# Salesforce Docs Portal

Official Salesforce documentation in formats designed for agents, LLMs, and direct HTTP retrieval.

## Documentation Collections

- [Admin](/admin/llms.txt): Salesforce administrator and end-user help across Salesforce products.
- [Architect](/architect/llms.txt): Salesforce architecture guidance for designing secure, reliable, and integrated solutions.
- [Developer](/developer/llms.txt): Salesforce APIs, programming guides, SDKs, and reference documentation.
- [Legacy Developer](/legacydeveloper/llms.txt): Legacy Atlas-format Salesforce developer reference that is migrating to the Developer collection. Status: Deprecating.
- [MuleSoft](/mulesoft/llms.txt): MuleSoft Anypoint Platform, connectors, DataWeave, runtime, and related tools.
- [Tableau](/tableau/llms.txt): Tableau Desktop, Server, Cloud, Prep, Public, APIs, and Blueprint documentation.
